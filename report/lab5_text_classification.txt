1. CÁC BƯỚC TRIỂN KHAI

Để hoàn thành các mục tiêu của bài Lab về Word Embeddings, tôi đã xây dựng hệ thống với các thành phần sau:

1.1. Module Word Embedder (Task 1 & 2)
- File: src/representations/word_embedder.py
- Chức năng:
  + Tải và quản lý model pre-trained `glove-wiki-gigaword-50` bằng thư viện Gensim.
  + Cung cấp phương thức `get_vector(word)` để lấy vector biểu diễn của từ.
  + Cung cấp phương thức `get_similarity(w1, w2)` để tính độ đo cosine similarity.
  + Cung cấp phương thức `embed_document(doc)`: Thực hiện tokenize văn bản và tính trung bình cộng (mean) các vector từ đơn để tạo ra vector đại diện cho cả văn bản.

1.2. Huấn luyện Model Word2Vec với Gensim (Task 3)
- File: test/lab4_training_demo.py
- Dữ liệu: Sử dụng tập dữ liệu UD_English-EWT (en_ewt-ud-train.txt).
- Quy trình:
  + Đọc dữ liệu thô và tiền xử lý (tokenization).
  + Khởi tạo model Word2Vec với cấu hình: vector_size=100, window=5, min_count=1.
  + Huấn luyện và lưu model xuống file `results/word2vec_ewt.model`.

1.3. Huấn luyện Model phân tán với Apache Spark (Task 4)
- File: test/lab4_spark_demo.py
- Công nghệ: PySpark (Spark MLlib).
- Mục đích: Minh họa quy trình huấn luyện trên tập dữ liệu lớn (Big Data).
- Quy trình: Khởi tạo Spark Session -> Load dữ liệu JSON -> Spark Tokenizer -> Train Word2Vec -> Find Synonyms.

1.4. Trực quan hóa dữ liệu (Task 5)
- File: test/lab4_visualize.py
- Phương pháp: Sử dụng thuật toán PCA (Principal Component Analysis) để giảm chiều dữ liệu từ 50 chiều (Glove) xuống 2 chiều, sau đó vẽ biểu đồ Scatter Plot để quan sát sự phân bố của các từ.

3. PHÂN TÍCH KẾT QUẢ

3.1. Đánh giá độ tương đồng (Similarity)
- Kết quả thực nghiệm cho thấy model pre-trained (Glove) nắm bắt tốt ngữ nghĩa của từ.
- Ví dụ: Độ tương đồng giữa 'king' và 'queen' (khoảng 0.7-0.8) cao hơn so với 'king' và 'apple' (gần 0).
- Các từ tìm được tương tự với 'computer' thường là: software, technology, pc, hardware... (đúng ngữ cảnh).

3.2. Phân tích biểu đồ trực quan hóa (Visualization)
- Biểu đồ PCA (file results/embedding_plot.png) cho thấy các cụm từ có nghĩa gần nhau sẽ đứng gần nhau trong không gian 2D.
- Quan sát cụ thể:
  + Nhóm từ chỉ trái cây/thực phẩm (apple, orange...) tụ lại một góc.
  + Nhóm từ chỉ người/hoàng gia (king, queen, man...) tụ lại một góc khác.
-> Điều này chứng minh Word Embeddings đã mã hóa thành công ngữ nghĩa vào không gian vector.

3.3. So sánh Pre-trained Model và Self-trained Model
- Pre-trained (Glove):
  + Ưu điểm: Từ vựng phong phú, vector chuẩn xác do train trên Wikipedia (hàng tỷ từ).
  + Nhược điểm: Kích thước file lớn, tốn RAM.
- Self-trained (Word2Vec trên tập EWT):
  + Ưu điểm: Nhẹ, học được đặc trưng riêng của tập dữ liệu huấn luyện.
  + Nhược điểm: Do tập dữ liệu en_ewt-ud-train.txt khá nhỏ, chất lượng vector kém hơn, nhiều từ không tìm thấy (OOV).

4. KHÓ KHĂN VÀ GIẢI PHÁP

- Khó khăn 1: Việc cài đặt PySpark trên Windows thường gặp lỗi thiếu winutils.exe hoặc lỗi Java Home.
  -> Giải pháp: Cài đặt JDK phiên bản 8 hoặc 11 và thiết lập biến môi trường đúng cách. Chạy Spark ở chế độ local[*] để đơn giản hóa.

- Khó khăn 2: Xử lý OOV (Out-Of-Vocabulary) khi nhúng văn bản. Nếu văn bản chứa toàn từ lạ, chương trình có thể bị lỗi chia cho 0 hoặc trả về None.
  -> Giải pháp: Thêm điều kiện kiểm tra. Nếu không tìm thấy vector nào, trả về vector toàn số 0 (Zero Vector) để đảm bảo tính toán tiếp theo không bị lỗi.
